# 风格基因

> 字是图形，取字成符；安静、准确，像一句话说到最后一个字。

这一章描述**审美与构成**，不描述具体用哪个字母、哪种颜色。每条基因都写明：是什么、为什么、试金石、常见误区。本风格不限行业：它是一种审美取向，用户按自己的喜好选用。

## 本风格以字为标

静几何是一种**字体型**的标志风格：标志由从零定制的中英文字形构成，字被设计到可以当作图形来看；图标（符号）由字标里的元素组合或改造而成。

所以选用本 skill，就等于用户明确要求“以字为标”。共用五章按图形标志写成，本风格对其中几条的替换集中列在 `SKILL.md`“本风格对共用章的替换”，每个项目在 `decisions.md` 第一行写明。例外不等于放宽：本风格用下面的“字形图形化”标准代替“首先是图形”那一关，要求同样严。本风格说的“符号”，就是共用章说的图形标志（图标）。

**字形图形化的四个判断**（代替“怎么判断图形感”）：
1. **读不懂也成立**：给一个不认识这种文字的人看，整个字标读成一个被设计过的形（有统一的外形、节奏和重心），而不是“一行打出来的字”。
2. **符号能独立成物**：从字标里取出来的符号，第一眼是一个紧凑的、有分量的面，能做成 App 图标、徽章、印章。去掉颜色缩到 32 px，它仍是一块形，而不是两三根笔画围出的线框。
3. **看得出同源**：并排看字标与符号，说得出符号取自字标的哪一处或哪几处。
4. **剪影有辨识度**：字母可以认得出，但字标不会被当成一款常见字体打出来的字，符号不会被当成素材网站上现成的字母组合或一个常见图标。

## 核心构成：字成一体，取字成符

- **字成一体（主）**：一整套定制字形按同一种几何语法构造，整个词的剪影、节奏、灰度被当作一个图形来设计。字是主体，安静、精确、中性。
- **取字成符（次）**：从字标里取出一处或几处元素——字母、字母的一部分、标点或笔画都可以——把几处组合起来，或把一个字形切开、错位、移动一部分，成为一个紧凑、有面的符号（一个字形切开后的两部分算两处）；重叠处、共用处或被移动的那一处，就是符号的签名。方式见 `creative-methods.md`。符号可以用同一套语法加粗一档（竖笔约为字标的 1.2–1.6 倍），让它在小尺寸下仍是一块面。单个字形的变形要靠一条关系或名字的意思绑定这个名字。
- **一种信号连起二者**：同一种信号（通常是唯一的强调色，或最纯的几何）同时标出字标里的这几处和符号，看字标就知道符号从哪里来，看符号就想到字标。组合的几处之间由一条量得出的关系绑定。

只做“字成一体”，字标只是一款好看的字体，没有记忆点；只做“取字成符”，符号和字标成了两件事，是拼搭。两者都要。

## 形式语言：锁定什么，不锁定什么

**锁定（决定这是静几何）**

| 层 | 本风格是什么 | 同一路的作品（帮助理解，不照搬） |
|---|---|---|
| 字的构造 | 字由几何零件构造，不是书写出来的；整套字母与中文笔画共用一套零件和规则 | 包豪斯的通用字体；克劳威尔《新字母表》；DIN 1451 |
| 曲线 | 修正几何：曲线介于圆与方之间，曲率连续，转角按同一规则柔化 | 皮特·海恩的超椭圆；连续曲率的产品与界面圆角 |
| 秩序 | 模数与基准：一个基准尺寸生成所有字形与符号 | 勒·柯布西耶《模度》；瑞士网格 |
| 对比 | 大静小响：中性的字形大面积，一处或一对信号把关键元素分离成图形 | 只把一个字母上色的经典字标；功能主义产品唯一有颜色的按键 |
| 细节 | 修正即性格：交接收细、端头平切、出格，其中一处放大成签名 | Bell Centennial 的墨阱；当代展示字体的墨阱细节 |

**不锁定（每个项目重新决定）**：用哪几个字母或笔画组合、怎么组合；大小写；字重与字宽；方度偏圆还是偏方；信号色的色相；信号是一处还是一对；材料与构图。

## 九条基因

### 1. 字即图形：构造，不是书写
**是什么**：每个字由几何零件（修正过的弧、直段、平切的端头）构造出来，不模仿笔写；整个词的外形、节奏、灰度被当作一个图形来经营。至少有一处**整个词层面**的设计：共用笔画或连写、贯穿全词的同一种签名、按词的轮廓调整的升部与降部、被组合的元素在词里的位置……让它不是“一款字体打出的一行字”。
**为什么**：构造出来的字，读起来像被设计的物件；写出来或打出来的字，读起来只是信息。（`philosophy.md` 第 1、2 条）
**试金石**：读不懂这种文字的人看，它是一个被设计过的形吗？把字标涂成剪影，外形有节奏、有辨识度吗？和一款常见几何无衬线字体打出的同一个词并排，说得出三处不同吗？
**常见误区**：拿现成字体改几笔；每个字母各有一种构造；字距随手，词的灰度忽深忽浅；方度高、字身宽、端头平切三项同时拉满，整套字像一款现成的方形展示字换了字母——三项里至少一项往反方向拧，性格要按品牌拉开。

### 2. 一套语法，中英同构
**是什么**：英文整套字母和中文字标用同一套零件与规则：同样的曲率、端头、收细、粗细补偿；至少一种元素中英共用（例如中文的点画与英文的标点同为一种纯几何）。
**为什么**：中英割裂是拼搭感最直接的来源；同一套语法让双语像一个人设计的。
**中文要单独下功夫**：中文不是把英文的零件硬套上去。部件比例、中宫、重心按汉字的结构来定，再统一端头、曲率与粗细补偿。笔画最多的字先做，用它定整体灰度，再按 `craft.md` 给它单独减重（常见 5–8%）。字面高度从英文 x 高的 1.3–1.4 倍起试，以并排看灰度与视觉高度相当为准。中文字标一般不小于 20–24 px 高，更小时改用英文字标或符号。
**试金石**：盖住字标里的关键字母，其余字母仍是一家人吗？中文和英文上下排，说得出共同的规则吗？中文字标和一款优秀的中文黑体并排，结构（中宫、重心、部件占比、疏密）不比它差，只是语法不同吗？最繁的字 32 px 高时不糊吗？
**常见误区**：只设计出现在名字里的几个字母，换一个词就露馅；中文用系统黑体；中文比英文重或轻一截；为了同构把部件压扁、挪位，汉字的结构变别扭。

### 3. 修正几何
**是什么**：圆略方、方略圆，曲率连续，所有转角用同一种柔化规则；全图只用一个“方度”。唯一的例外是第 7 条：承载意义的一两处可以用最纯的几何。
**为什么**：纯几何显得机械，随手的曲线显得随意；修正几何理性又耐看，也是今天屏幕与设备的曲线语言。（第 4 条）
**试金石**：所有曲线说得出同一个构造参数吗？放大 400%，曲线是否连续？
**常见误区**：圆形字用正圆、方形部件用直角，两种语言打架；把柔化做成圆滚滚。

### 4. 取字成符
**是什么**：符号不是另外画的，而是从字标里取出元素组合或改造而成。方式很多（`creative-methods.md` 的组合方式表），可以组合几处，也可以只取一个字形加以改造；每个项目从自己名字的字形里找最有意思的那一种。结果要生成一个新的面，而不只是把几个字母摆在一起。
**为什么**：符号与字标同源，整套识别才是一个声音；用户看符号就想起名字。（第 5 条）
**试金石**：符号单独拿出来，是一个紧凑、有面、能独立成物的形吗？说得出它取自字标的哪一处或哪几处、怎么组合或改造的吗？换一个同字母的品牌，它还成立吗？
**常见误区**：符号只是首字母放进一个方块（太普通）；组合的几处毫无关系，只是摆在一起；为了图形感把字拆成几根线；符号由两三根细笔画围成，没有面；用一个字母和它自己的旋转或镜像拼成对称的形——这在现成的字母组合标里极常见，每轮最多一张卡，推荐前先查同字母的现成组合标。

### 5. 关系是算出来的
**是什么**：组合在一起的几处，由一条量得出的关系绑定：同一个尺寸、同一个角度、落在同一条线、一处恰好由另一处推出……这条关系可以写成一句话或一个式子，并且对画出来的形本身成立。
**为什么**：随手的组合像拼贴；算出来的组合让人觉得“本来就该这样”。（第 3 条）
**试金石**：问“为什么是这个大小、这个位置”，答案能写成式子吗？挪一点，是否立刻不对？
**常见误区**：关系只写在说明里，形上看不出来；每个项目都用同一种关系。

### 6. 色彩分离：大静小响
**是什么**：字形大面积中性、冷静；只有组合进符号的那几处用信号色（或最纯的几何）分离出来，变成图形单元。信号面积很小，却第一眼被看见。单色时，靠形与纯度保住这几处。
- 符号整体都由取来的元素组成时，只点亮其中被移动、被借用或被共享的那一处，字标里点亮同一处。点亮后在词里拼出意外的字或词，就换一处。
- 第 3、4 阶段的双色版用中性色加一个**暂定**信号色，标注“暂定”；它只用来看结构，选一个与该行业惯用色、已有案例都不同的色相，正式色相到第 5 阶段比较后再定。第 2 阶段的黑白速写用中灰标出要点亮的地方。
**为什么**：一个词里只有一两处被点亮，这几处立刻从“字”变成“图形”，也自带一个图标；颜色只给关键处，是功能主义的传统。（第 6 条）
**试金石**：第一眼是不是落在被点亮的那几处？去掉颜色，它们是否仍然可辨？
**常见误区**：给多个字母各上一种颜色；信号太大、主次颠倒；用渐变代替分离。

### 7. 最小的元素成为图形
**是什么**：字里最小的元素——一个点、一个横、一个钩、一处开口或内白，名字里有标点时也包括标点——可以被提升为最纯的几何，承载意义；其余字形做修正。越重要越纯粹。名字里没有标点，就从笔画里选，不要为此加标点。
**为什么**：字里最小的元素最容易变成图形，也最容易成为全套识别的“种子”（辅助图形、动态、界面状态都从它长出来）。（第 7 条）
**试金石**：说得出哪一个元素“最纯”、为什么是它吗？去掉颜色，它还是第一眼被看见的吗？
**常见误区**：所有点都同样纯，没有主次；为了“有设计”给每个标点都加花样。

### 8. 修正即性格
**是什么**：视觉修正做到位——出格、交接收细（墨阱式的刀口）、端头平切、横细竖粗——其中一处放大成看得见的签名，并在整套字里保持一致。
**为什么**：工程修正原本为了“看起来对”，放大一处，就成了精密而当代的性格。（第 8 条）
**试金石**：放大 400% 修正是否系统一致？整个字标（含升部与降部）32 px 高时，那一处签名还在吗（缝与刀口至少一个完整像素）？
**常见误区**：修正太细，小尺寸全部消失；处处都在“设计”；用发光、金属质感冒充精密。

### 9. 理性的体温
**是什么**：精确，但不冷漠：小写的亲和、略圆的修正、一个会心的组合，留一处人的温度。
**为什么**：冷冰冰的正确记不住；有一点体温的理性，才让人愿意亲近。（第 10 条）
**试金石**：它只是正确，还是也让人会心？温度来自字形与组合，而不是来自暖色或可爱的造型？
**常见误区**：把温度做成卡通字；把理性做成没有任何情绪的标准件。

## 风格坐标：像谁，不像谁

| 像（气质上） | 不像 |
|---|---|
| 包豪斯与瑞士的构造字：字由几何生成 | 现成字体打出来、只换了颜色的字标 |
| 只点亮一个字母的现代主义经典字标 | 每个字母都在“表演”的花字 |
| 屏幕与设备的连续曲率 | 生硬的直角拼装或卡通的圆滚滚 |
| 当代展示字体的墨阱与平切 | 发光、渐变、金属的“科技风” |
| 功能主义产品的信号色 | 多色拼接的热闹 |

## 旋钮：可以变的部分

形式语言守住风格；下面这些旋钮每个项目都要重新拧。**新项目的最终方案至少要有两个旋钮的取值与 `cases/index.md` 里所有案例明显不同**（组合方式不算在内，它本来就必须不同），除非用户明确要求。案例的取值在 `cases/index.md`，列完候选再看。

| 旋钮 | 范围 |
|---|---|
| 组合方式 | 见 `creative-methods.md` 的组合方式表 |
| 大小写 | 全小写 · 首字母大写 · 全大写 |
| 方度 | 接近圆 · 圆方之间 · 接近方（用超椭圆时，指数 n：2 是正圆，约 2.5 偏圆，3–3.5 圆方之间，4 以上接近方。用案例 `geo.py` 的三次曲线参数 k 时，n ≈ ln 2 ÷ (−ln((4+3k)/8))：k 0.55 → 2，0.62 → 2.2，0.70 → 2.6，0.80 → 3.1，0.90 → 3.9） |
| 字重与字宽 | 轻到粗；窄到宽（字标偏轻时，符号可以加粗一档） |
| 信号 | 一处 · 一对；颜色或纯几何 |
| 签名修正 | 交接收细 · 端头切法 · 出格 · 一处特殊弧度 · 一处特殊角度；并排看图判断是否真的不同，不只看名字 |
| 温度 | 冷（碳黑、冷灰）到略暖（骨白、暖灰），不到奶油米白 |
| 信号色 | 任何一个高饱和色相，由概念与查重决定（第 5 阶段） |
| 材料想象 | 工业涂层 · 阳极氧化金属 · 玻璃 · 印刷纸 · 屏幕光 |

## 模糊词在本风格里的意思

| 用户说 | 在静几何里是 |
|---|---|
| 高级、有质感 | 修正更系统、曲率更连续；字距按面积排得更匀；信号更少、更准 |
| 有张力 | 大静小响拉得更开；组合的关系更严格、更出人意料 |
| 科技感 | 构造字的精度、连续曲率、墨阱式的刀口、参数化的一致性；不是光效与电路纹 |
| 潮流、年轻 | 字更宽或更轻、方度更有个性；签名修正更大胆；信号色更明快 |
| 现代、国际化 | 小写或中性的大写；去掉地域与行业的表面符号；中英同构 |
| 温暖、亲和 | 小写、更接近圆的方度；一处会心的组合；不是加暖色 |
| 太普通、像打出来的字 | 字的构造是否统一？剪影有没有被经营？符号是不是只是首字母放进方块？ |
| 有 AI 味、拼搭感 | 找出不是从基准与语法推出来的元素；符号与字标是否同源 |

## 整体试金石

交付前整体看一遍。第 3 阶段（黑白为主，附一版只标出信号的双色版）判断第 1–6 问；其余到第 5 阶段有了完整字标与配色再判断。

1. **字形图形化**：读不懂这种文字的人看，字标是一个被设计过的形吗？符号是一块有分量的面、能独立成物吗？
2. **取字成符**（正向的风格判断）：说得出符号取自字标的哪一处或哪几处、怎么组合或改造的吗？
3. **关系算得出**：符号里的关系（几处之间，或切开的两部分之间）能写成一句话或一个式子吗？
4. **修正几何**（正向的风格判断）：所有曲线和转角出自同一个方度吗？
5. **大静小响**：第一眼落在被点亮的那几处吗？去掉颜色仍可辨吗？
6. **记得住**：字标与符号的剪影、反白、32 px 都有辨识度，不像常见字体打出来的字，也不像常见图标。
7. **一套语法**：盖住关键字母，其余字母、中文仍是一家人吗？
8. **修正即性格**：说得出那一处签名细节吗？整个字标 32 px 高时它还在吗？
9. **现代感从哪里来**：说得出它的现代感、科技感来自哪几处构造（见 `philosophy.md`“现代感、潮流感、科技感从哪里来”），而不是来自效果？
