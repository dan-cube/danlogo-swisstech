# 质量关卡

不过关不交付。每个风格 skill 还会在自己的 `style-dna.md` 里有风格试金石；这里的关卡与风格无关，所有 danlogo skill 都一样。

**用词**：本系列把标志的主体叫**图形**，不叫“符号”。“符号”这个词容易把人带向字、标点和界面图标——那是字体设计，不是图形标志。下文的“公共符号”只指国旗、宗教、交通这类需要避开的东西。

## 怎么判断图形感

logo 首先是一个图形。最常见的跑偏是：为了“少”和“准”，形被拆成几根线、几个笔画，最后变成一个字、一个字母、一个标点或一个界面图标。它可能很精致，但那是字体设计，不是图形标志。

每张速写和每个原型都回答四个问题：

1. **第一眼读成什么**：遮住品牌名，设想一个不认识中文的人来看。他说“这是一个字 / 字母 / 标点 / 数字 / 按钮图标”，不过；他说“这像一个……”，并说得出一个东西、一个画面或一个形，才过。
2. **有外形、有面**：用一张纸能把它剪出来，剪下来是一个完整的形，而不是几根散开的线。线可以用，但要围成形，或者成为形的边。
3. **能独立成物**：做成一枚徽章、一块招牌、一个立体物件、一个 App 图标，它是一个“东西”。
4. **有意象**：说得出它让人想到的一个画面或感受，可以很抽象，例如一道光、一处安放、一次闭合。只说得出它的构成（“一横加一竖”“一块加一缝”），不过。

图解也有图形感，但它照现实的样子画，常常像一个已有的图标；所以过了图形感，还要过辨识度。

**例外**：用户明确要纯字标、字母标或以字为标时，照用户的要求做，跳过本项，并记入 `decisions.md`。

## 怎么测辨识度

“想得好，画出来却像一个常见图标”是第二常见的失败。每张速写和每个原型都做下面六项：

1. **剪影与反白**：把形涂成纯黑只看外轮廓，再看黑白反转的版本，按类别和常见的东西比较，能明显区分才算过：
   - 界面图标：菜单、播放、暂停、电池、定位、对勾、箭头、心形，以及侧栏、分栏、窗口这类布局图标
   - 框与屏：相框、照片、屏幕、窗口、瓷砖、App 的方块
   - 图表与工程符号：柱状图、折线、条形码、电路与电子元件符号
   - 器物与家具：碗、杯、椅、台座、门
   - 身体与动物：眼、耳、靴、驼峰
   - 徽章与建筑：皇冠、城垛、盾、金字塔、牌坊
   - 社团与秘传符号：矩尺与圆规、三角形中的眼
   - 字母、数字与标点

   环形、开放的线形涂黑后几乎没有区分度，这时以反白和下一项为准。
2. **外形本身**：外轮廓是方、圆、三角、山形、卵形这类常见外形时，剪影帮不上忙，辨识度全靠内部。这时内部的关系要一眼可读，32 px 时还在；做不到，就换一个外形，或者让签名参与外轮廓。好的图形标志，往往单看外形就已经认得出。外形可辨识，不等于把形做成一整块实心剪影：外形也可以由实与空一起围出。
3. **十字描述与重画**：用不超过 10 个字描述这个形。如果这句描述也能套在一个常见图标上，就算不过。然后只凭这句描述重画一次：画出来的如果不是它，或者丢了它的关键，说明这个形记不住。（有人可以问时，再加“看三秒后凭记忆画出来”。）**陌生不等于辨识度**：冷僻的东西不像任何图标，却同样记不住。
4. **签名细节**：能指出一处只属于它的关系或细节（见 `craft.md` 的手法库）。指不出来，就还是图解。**签名要看得见、站得住**：32 px 时还在。它可以是一块空、一条关系，不必靠墨多——要的是醒目，不是分量。发丝缝、细小的缺口、微小的角度变化，到 32 px 都会消失，不能单独当签名。概念本身是“看不见”（无痕、安静、隐藏）时，签名不能也看不见：用一个看得见的关系去说“看不见”。盖住签名（签名是一块空时，就把空填上），剩下的如果正好是一个常见图标，说明签名太弱或太靠边，要让它更明确，或者让它参与外形。
5. **去掉故事**：不讲概念，只看形——它本身好看、有张力吗？
6. **缩小**：32 px 与 16 px 下，主标志或它的小尺寸版还保有签名细节吗？第 3 阶段只判断“能不能做出这样的小尺寸版”，不因主标志在 16 px 不成立而淘汰它。

第 2 阶段用速写做自查，结论写进概念卡（速写也可以跑 `scripts/review.py`）；第 3 阶段起每个原型都要过这六项，用 `review.py` 一次生成剪影、反白、32 / 16 px、头像和墨色比例，结果随原型一起给用户看。

**不要用偏离本风格的手段换辨识度。**
- 小尺寸和剪影测试天然偏爱大块实心的形。本风格是轻的，就不要为了过测试越做越粗、越做越满；本风格是繁的，就不要为了缩小把细节拆光。小尺寸交给单独的小尺寸版。
- 不要把形拆成几根线来换“少”，那会把图形变成字或符号，丢掉图形感。

辨识度应该来自一个完整的形，加上本风格自己的关系、对比与取舍。

## 什么是 AI 味

“AI 味”是用户最常否定的感受之一：东西看起来“像是生成的”，而不是一个设计师想出来的。它出现在三个地方。

**形**
- 通用的几何拼装：几个圆、点、弧、线随意组合，换个品牌名也能用。
- 几根线、几个笔画拼成一个像字的东西，用“少”冒充设计。
- 对称、居中、网格、圆角都只是默认值，看不出任何一处经过判断。
- 每个元素都在“表达”某个意思，合起来却没有一个主要想法。
- **没有理由的效果**：渐变、发光、质感、立体、装饰被用来填空，而不是本风格需要。效果本身不是毛病，没有理由才是。
- 没有做视觉修正，细节显得机械。

**话**（概念说明、提案文字）
- 同一种句式反复出现，例如一再使用“X 不是……，而是……”的先否定再肯定。
- 排比、对仗堆叠；每一句都要升华。
- 空洞的大词：赋能、链接、未来、无限、智慧、生态、引领。
- 概念要解释很久才成立。

**过程**
- 先有形，再给它编故事。
- 为了显得全面而列出很多差不多的选项。

**怎么去掉**
- **具体**：说具体的字、具体的物、具体的动作，不说抽象的大词。
- **取舍**：明确说不要什么；每轮只推荐一个，说清理由。
- **像人说话**：一句话概念控制在 30 字以内，用平实的陈述句；同一种句式一轮里最多出现一次。
- **形先成立**：先让形本身说话，再写说明；说明只补充，不代替。

## 怎么查重

**三个时点**：原型初查（快）、定稿全查（全）、提案前复查（确认没有新的近似）。

**查什么**：
1. **文化与公共符号**：国旗（尤其是白底单色圆、十字、星、新月等结构）、宗教符号、政治符号、社团与秘传符号（矩尺与圆规、三角形中的眼等）、交通与安全标识、常见 UI 图标（加载、开关、单选按钮等）。
2. **知名品牌**：同色系、同结构的全球与中国知名品牌，尤其是名字相近的公司。
3. **同行**：同一行业、同一赛道的主要公司标志与 App 图标。
4. **常见手法**：判断这个手法是不是已经被广泛使用（例如“字标后加一个彩色句点”“两座山之间的负形”）。常见手法本身不是抄袭，但难以独占，要在提案中说明。

**怎么做**：
- 用文字描述搜索（例如“logo ring with dot inside”“负形 杯 山 logo”），中英文都要搜。
- 能看图时，浏览同结构的标志；在标志收录网站、App 商店里浏览同行。
- **只能文字检索时的最低要求**：中英文各至少 3 组描述形的关键词，每组再配上行业词；把查过的关键词和找到的结果记下来，并写明“没有做图形比对”。看不到图的网站不必硬浏览。
- 记录：找到的最接近的对象、相似在哪里、不同在哪里、风险等级（低 / 中 / 高）、建议。
- **不要把用户未发布的设计上传到任何第三方以图搜图服务**，除非用户明确同意。
- 结论里写明：这是初步排查，不能代替商标代理在商标局做的正式近似检索。名字本身的文字商标风险也要提醒。
- 写明查重手段的局限（例如中文检索不足、无法做图形检索）：“没查到”不等于“没有”。
- 概念依据的字源、典故如果有学术争议，提案里写成“一说”，不要当成定论。

## 怎么看渲染图

- 每次生成后，渲染为 PNG 并亲眼看；不要只看代码或 SVG 文本。
- 审看图包含：大图、32 px、16 px；黑白；反白；与已有方案并排。
- 发现问题先改代码再重新渲染，不手工修图。
