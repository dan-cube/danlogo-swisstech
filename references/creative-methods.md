# 创意方法

风格基因守住审美，创意方法负责**每次从名字里找到不一样的组合**。这一章在第 2 阶段（概念）和第 3 阶段（原型）使用。

## 目录
- 素材从哪里来：名字的字形与意思

- 走出图解：本风格偏爱的手法
- 概念卡格式

## 素材从哪里来：名字的字形与意思

本风格以字为标，素材首先是名字本身。先把下面的问题逐一回答，列出 10 个以上**组合候选**（哪几处、怎么组合、说明什么），覆盖至少三处来源，再挑。

1. **字形的结构**：名字的英文字母和中文笔画里，有哪些开口、圆、竖、横、点、钩、交叉、重复、对称？哪两处的形天然相似或互补？
2. **首与尾、内与外**：名字的第一个字形和最后一个、某个字母的外形和内白，能不能彼此呼应？
3. **中英之间**：中文和英文有没有可以共用的一笔、一个点、一个比例？
4. **标点与附加符号**：i 的点、句点、连字符、中文的点画，能不能承载意思？
5. **名字的意思**：名字说的是什么动作、什么变化、什么状态？哪一种组合能把这个意思“演”出来？
6. **品牌的关键一处**：如果只能点亮一处，品牌最想让人记住的是什么？它落在名字的哪一个字形上？

组合要能长成一个**紧凑、有面的符号**，同时让字标保持可读。名字的意思决定选哪种组合；字形的结构决定组合能不能成立。

- **主名优先**：素材先取品牌的主名（中英文）；“科技”“Records”“Clinic”这类描述词，用户把它当作名字的一部分时才用。
- **候选要跨类**：10 个以上候选至少来自三类——字形结构、首尾与内外、中英之间、最小的元素（点、横、钩、开口、标点）、名字的意思——并用到四种以上的组合方式。可以共用同一个字母，只要组合方式与关系不同。

**本风格自己的比喻不是素材。** 思想坐标里的说法——基准、模度、精密、修正——描述的是审美和方法。不要把品牌画成一件仪器或量具；素材在名字里。

## 方法：九步

### 1. 读名字的字形
把名字的英文和中文逐个拆开，记下每个字形的结构特征（开口朝向、圆的数量、竖笔位置、点画、升部与降部），在纸上或代码里并排画出骨架。

### 2. 先定字的语法（第 3 阶段开始）
定下基准与参数：字高与 x 高、竖笔宽、横向补偿、方度、刀口深度、端头切法。先画名字里最有代表性的五六个字母和中文最难的一两个字，确认语法成立。方度、字宽、字重按品牌的性格定，不要默认取同一组值。

### 3. 经营整个词
把整个词当作一个图形：剪影的高低节奏、灰度是否均匀、字距按面积排（直–直宽、圆–圆窄）；再做至少一处整个词层面的设计（共用笔画或连写、贯穿全词的签名、按轮廓调整的升降部、被组合元素在词里的位置）。
- 怎么做：把字标涂成剪影看；缩到整个字标 32 px 高看灰度；和常见几何无衬线打出的同一个词并排，写下三处不同。

### 4. 取字成符
从组合候选里挑 3 个以上，用不同的组合方式（见下节）各做一个符号。符号要紧凑、有面、能独立成物：去掉颜色缩到 32 px，是一块形，而不是几根笔画围出的框。字标偏轻时，符号可以用同一套语法加粗一档。

### 5. 算出组合的关系
组合的几处之间写出一条量得出的关系：同一尺寸、同一角度、同一条线、共用一笔、一处由另一处推出……并确认它对画出来的形本身成立。

### 6. 色彩分离
字形先在黑白里成立；再只把组合进符号的那几处分离出来（信号色或最纯的几何），其余保持中性。第 3、4 阶段附一版双色版：中性色加一个暂定信号色，标“暂定”，色相到第 5 阶段定。符号整体都由取来的元素组成时，只点亮被移动、被借用或被共享的那一处。

### 7. 放大一处修正成签名
从修正（交接收细、端头切法、出格、一处特殊弧度或角度）里挑一处，放大到整个字标 32 px 高仍看得见，全套保持一致。

### 8. 中文同构（第 3 阶段做关键字，第 4 阶段完成字标）
用同一套语法构造中文：端头切法、曲率、粗细补偿一致；部件比例、中宫、重心按汉字的结构来定，不硬套英文的 x 高。先用笔画最多的字定字重。找出一种中英共用的元素。和一款优秀的中文黑体并排检查结构，最繁的字 32 px 高不糊。

### 9. 留一度体温
在整套精确的规则里，留一处人的温度：小写的亲和、略圆的修正、一个会心的组合。只留一处。

## 组合方式

符号来自字标里一处或几处元素的组合或改造。下面是常见的方式，**每轮至少用三种不同的方式，同一种最多两张卡**；也可以发明新的。结果要生成一个新的面：重叠处、共用处、被移动的那一处，就是签名。

| 组合方式 | 做法 | 要注意 |
|---|---|---|
| 并置 | 两处元素按原样并排，靠一条关系相认（同色、同尺寸、同角度） | 两处要有关系，不只是摆在一起 |
| 叠合 | 两个字形部分重叠，重叠处成为新的形 | 重叠后仍能认出各自的来源 |
| 嵌套 | 一个字形放进另一个的内白或开口 | 两者共用一个尺寸或一条线；“开口恰好容下另一处实”这一种关系已被案例用掉，核心关系要换成别的 |
| 连写 | 两个字母共用一笔，连成一个形 | 共用的那一笔就是签名 |
| 截取 | 截取字标的一段（几个字母的局部）当符号 | 截取的一段要能独立成形 |
| 首尾 | 取第一个和最后一个字形（或标点），合成一个符号 | 首尾之间要有意思上的呼应；不能用案例的具体安排（`cases/index.md`） |
| 中英共用 | 中文的一笔与英文的一部分共用，成为双语共同的符号 | 两边都要读得出 |
| 反转 | 一个字形的内白反过来成为实形 | 反转后仍是一个完整的面 |
| 单字改造（错位、抬起、切开） | 只取一个字形，切开、错开或移动一部分；切开的两部分算两处 | 变化的量由基准算出；仍读得出原来的字形；要靠关系或名字的意思绑定这个名字，否则任何同字母的品牌都能照搬 |
| 自身旋转或镜像 | 一个字母和它自己的旋转或镜像拼合 | 现成字母组合标里极常见：每轮最多一张卡，推荐前先查同字母的现成组合标 |

## 走出图解：本风格偏爱的手法

在本风格里，“图解”指把名字用常规字体打出来，或只把首字母放进一个方块。下面的手法把字推成图形：

| 手法（`craft.md` 手法库） | 在本风格里的意思 |
|---|---|
| 字母构造 | 字由几何零件生成，不书写 |
| 字图融合 | 字的一部分同时是图形的一部分 |
| 精确的关系 | 组合的几处由一条可量出的关系绑定 |
| 极端的对比 | 中性的大面积字形与一两处信号 |
| 一处偏差 | 整齐的字里只有一处不同 |
| 截取 | 只取字标的一部分做符号 |

**守住风格**：
- 不要为了“图形感”把字拆成几根线；字形和符号都要有面、有分量。
- 不要用现成字体加特效代替构造。
- 符号不要和字标分家：符号里的每一部分都要在字标里找得到。
- **手法服从简报**：组合让名字难以阅读，或撞上简报的禁忌时，换组合。

## 概念卡格式（第 2 阶段，每轮 5 张）

```
C<编号> · <概念名>
素材：      <取名字里的哪几处字形>；<为什么是它们：意思上的理由>
组合：      <组合方式>；<组合后符号是什么样子>
一句话：
形：        <附黑白速写：字标的关键字母 + 符号；外形、面、主要关系>
关系：      <组合的几处之间那条可量出的关系>
自查：      <字形图形化四问（style-dna.md）；剪影与符号像什么、签名在哪>
越过：      <第一反应是什么；为什么越过>
方法：      <用到九步里的哪几步、上表哪种手法>
旋钮：      <组合方式 / 大小写 / 方度 / 字重字宽 / 签名修正（色彩到第 5 阶段再定）>
风险：      <可读性、与常见字标或图标撞形、关键场景是否成立>
延展与参照：<能否长成辅助图形、动态、界面状态；最接近的思想来源>
```

一轮的 5 张卡：至少用三种组合方式，同一种最多两张；至少 2 张的组合方式与 `cases/index.md` 里的不同。字母少、好组合集中在几个字母上时，可以共用字母，只要组合与关系不同；不要为凑数做弱卡——确实只有几个好方向时，如实说明，弱卡标“不推荐”。

## 防止同质化

- **候选要宽**：组合候选覆盖至少三处来源（上面的六个问题）。
- **案例只借方法，不借形式**：EonPoint 的首字母、句点、开口的尺寸关系，是那个名字的答案。
- **组合不重复**：不能用 `cases/index.md` 里登记过的具体组合；同一个项目里，同一种组合方式最多两张卡。
- **先查现成的字母组合**：推荐前，用“这几个字母 + monogram / 字母组合标志”检索一次素材网站与商标库；撞上现成组合的，换组合或换关系。
- **把不同项目并排**：如果几个项目的符号用的是同一种组合方式、只换了字母，就是本风格的惯性，至少换掉两个。
- **旋钮要拧**：最终方案至少两个旋钮与所有案例明显不同（见 `style-dna.md`）。
- **警惕默认答案**：本风格的基因和读过的示范，会把 AI 推向某几类反复出现的形。这里不点名这些答案；用 `exemplars.md` 开头的方法自己识别。
- **按审美判断**：用形式语言、九条基因与思想坐标的自检判断风格，而不是看元素。
- **交付前对比**：把新方案和已有案例放在一起，一眼要能分开。
