## 原则：从核心构成关系长出来

静几何的延展，不是把标志贴到各处，而是让“字成一体，取字成符”在更大的尺度上继续成立：定制字的零件与语法长成辅助图形、图标和标题字；组合进符号的那几处（以及它们的信号）成为整套识别的种子——动态、界面状态、海报都从它们长出来；一切尺寸来自同一套模数；每一页、每个场景都是大静小响，只点亮一处。最容易走样的地方有三个：信号色在页面上越用越多，变成装饰；转角和曲线在不同物料上各用各的；动态做成炫技的光效，而不是讲标志的那一个想法。

## 1 体系

| 项 | 本风格怎么做 | 为什么 |
|---|---|---|
| 辅助图形 | 从字标里长出来：把一个定制字形放到极大并裁切、把组合进符号的那几处单独放大做主角、用字的零件或模数单元铺一片秩序并只点亮其中一处，或把构造线本身做成图形。一个画面只用一种 | 辅助图形要讲同一个想法，不能另起一个故事 |
| 版式与网格 | 非对称的模数网格，网格单位由标志的基准推出；留白多于内容；阅读顺序清楚；对齐都有理由；圆角与曲线沿用标志的方度 | 模数与基准是本风格的支柱 |
| 字体系统 | 定制字用于标志与少量大标题（整套字母是一项资产）；正文用一款中性、修正好的无衬线（中英文配对），数据与标签用等宽或窄体；层级靠字号和字重拉开，不靠颜色 | 定制字是品牌的声音，正文要安静 |
| 色彩比例 | 中性色占绝大部分；信号色很少，只给关键信息、关键动作和辅助图形的那一端；变色只换信号色色相与中性色冷暖 | 颜色越少越有力量；颜色是信息 |
| 图片与插画 | 冷静的自然光或柔和的棚光；近距离看材料与细节；构图有明确的主体和大块安静的背景；不用抽象的光效素材 | 图片也要“只点亮一处” |
| 图标 | 与标志同一套修正几何（同样的方度、端头、收细）；以面为主；尺寸体系从标志的基准推出 | 图标是标志规则的延展 |
| 动态的性格 | 一到两秒；动的就是“取字成符”：字标展开，被组合的那几处移动、合拢成符号（或反过来）；缓入缓出、到位时干脆；终点帧是标志 | 动态讲同一个想法，不炫技 |

## 2 场景

| 项 | 本风格怎么做 |
|---|---|
| 最能证明本风格的场景 | 产品界面与对话界面（信号色只标“完成”或“关键动作”）、官网首屏、导视与空间标识、印刷品（名片、信纸）、工业表面与设备铭牌；这些场景里秩序与精度最显眼 |
| 材料与工艺 | 性格是精密、干净、冷静：涂层、阳极氧化、刻、压印、精细的丝印；信号色像设备上唯一的指示，只出现在一处 |
| 场景示意的气质 | 平面、干净、冷光；中性的灰与深色为底；角度端正；画面里只有一处信号色；占位信息明确标出 |

## 3 提案

| 项 | 本风格怎么做 |
|---|---|
| 版面 | 16:9 模数网格；左对齐；每页一个想法；大量留白；图与字分区清楚 |
| 字与色 | 中性无衬线做标题与正文，等宽体做编号与色值；深浅两种底交替；信号色只做页面上的一个标记（例如编号前的一处、关键数字） |
| 叙事的语气 | 冷静、确定、像工程师讲方案：先说名字，再说理念，再说规则，再给证据；不用夸张的形容词 |
| 页面节奏 | 陈述页（一句话）与证据页（构造图、对比、场景）交替；规则页是高潮——把基准、方度和“信号怎样算出来”画清楚 |
| 封面 | 封面是标志的第一个场景：深色或浅色底上只有标志与一行说明，信号色只出现在标志里 |
| 证据的呈现 | 构造图、校样（单色、反白、小尺寸）、对比图都排在同一网格里，标注用等宽小字 |

## 4 规范手册

沿用提案的版面规则：同一网格、同一套字、同一种标注方式。每一页先给结论（怎么用），再给证据（为什么）。手册本身也只点亮该点亮的地方。

## 延展试金石

交付第 6–8 阶段前，用这几个问题整体看一遍：

1. 遮住标志，看任意一页提案、一个场景、一段动态：还认得出是这个品牌、这个风格吗？
2. 辅助图形能说出它从标志构成的哪一部分长出来吗？曲线和转角用的是标志的方度吗？
3. 每一页、每一个场景，信号色是不是只出现在一处，而且那一处是关键信息？
4. 每一页的阅读顺序清楚吗：从哪里开始读、在哪里停下？
5. 动态讲的是不是“从开始到完成”，终点帧是不是标志？
6. 和标志并排看，体系里有没有哪一样东西的审美不属于本风格（某个默认模板、某张素材图、某种动效）？

## 案例：EonPoint「首尾」怎么延展

只借方法，不借形式：这里的具体颜色、字、版式是那个品牌的答案。

| 环节 | 案例里怎么做 | 体现了哪条原则 |
|---|---|---|
| 辅助图形 | 三种手法：把开端的字形放到极大并裁切；把信号单独放大做主角；一片等距的中性小单元里只点亮一个 | 从标志构成长出来；只点亮一处 |
| 动态 | “落点”：信号从中间的一个字形上起身，划一道弧，落到句尾；终点帧是中英组合 | 信号最后到位；终点帧是标志 |
| 色彩 | 碳黑与冷灰为主，信号橙只在两端与一个按钮上；另备两套变色（只换信号色与中性冷暖） | 色彩是信息；变色不改规则 |
| 数字场景 | 官网首屏深色底，大标题的句号用信号色；对话界面里“任务完成”后面跟一个信号色的小标记 | 信号只标“完成” |
| 印刷与空间 | 名片、信纸、工牌、形象墙、展会立柱都只有一处信号色 | 每个场景一个重点 |
| 提案 | 25 页，深浅两种底交替；每页左上角一个等宽小标签，前面一处信号色；规则页（信号的尺寸怎样算出）是全篇高潮 | 讲规则、给证据 |
