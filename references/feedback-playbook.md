# 反馈对照表：反馈 → 诊断 → 动作

用户的反馈常常很短。先对照这张表判断真正的问题，再动手。“高级”“有张力”“年轻”这类模糊词，同一个词在不同风格里意思不同：先查本风格 `style-dna.md` 的“模糊词在本风格里的意思”。

具体项目的反馈原话记录在各 skill 的 `cases/` 里。某条反馈规律如果适用于整个 danlogo 系列，在第 9 阶段建议加入 `danlogo-maker/standard` 的这张表，再同步到各 skill。

| 用户可能说 | 通常的问题 | 动作 |
|---|---|---|
| 啰嗦、繁琐、越改越丑 | 元素、层级、颜色超出了本风格需要的量；在原图上不断打补丁 | 退回上一阶段，回到一个母题、一个主想法；做删除测试；繁复的风格也要检查每一层是否服从同一个主想法 |
| 密集恐惧、太密 | 重复的小元素过多、间距太小、没有节奏 | 减少数量或拉大间距；或把重复组织成有节奏的图案；仍不行就换母题 |
| 不成熟、AI 味、拼搭感 | 图形和字两套语言；用现成字体；元素来源不一 | 定一套构成语法，让图形与字同源；字从零绘制；统一线宽或粗细关系 |
| 不像 logo、像字体、像个符号 | 母题来自字形，或形被拆成几根线、几个笔画；没有外形和面 | 回到第 2 阶段，换一个能长成图形的母题（事物、现象、动作、空间）；用面和外形来画；过 `quality-gates.md` 的“图形感” |
| 辨识度不强、像个图标、记不住 | 停在母题的图解，没有签名细节，或签名太小 | 用 `craft.md` 手法库里本风格偏爱的手法重做，让签名成为形的主体；不要靠加元素解决 |
| 闷、一块黑、像剪影 | 只有外轮廓在说话，内部没有被设计 | 让内部的关系（空、层次、结构、图案）成为看得见的设计，回到本风格的核心构成关系；不要只加一道缝 |
| 太重、太硬、不够轻 | 为了辨识度或小尺寸，把主标志做粗做满 | 主标志回到本风格的力度，辨识度从外形、关系和对比里找；另做一个加粗的小尺寸版 |
| 不够高级、不够艺术 | 太直白（行业俗套、字面图解）；效果没有理由；颜色是行业默认 | 越过第一反应；回到本风格对“高级”的翻译（`style-dna.md`“模糊词在本风格里的意思”）；去掉没有理由的效果 |
| 太规整、死板 | 每一处都按默认对齐，规则里没有选择 | 在规则里做一处有理由的选择（偏差、对比、节奏变化）；对称的风格就让对称更有分量，而不是随手打破 |
| 太复杂（说的是字） | 字的变化太多，每个字母都在“设计” | 字退到只剩骨架，只保留与图形呼应的一处细节 |
| 太幼稚、太亮 | 超出了本风格的语气 | 回到风格章的语气与色彩规则；需要时降饱和、减色、收紧圆角 |
| 都不满意 | 方向错了，不是细节问题 | 不要微调；回到第 2 阶段换母题，或回到第 1 阶段重新确认品牌本质 |
| 太具体、太死板（说的是规则或方案） | 规则落到了具体颜色、形状或工艺上 | 把具体项移到案例里，规则只保留原则、理由和自检问题 |
| 喜欢某个思路 | 抓住了用户的审美 | 记录原话与原因；在后续轮次延续这个思路，但换形式；第 9 阶段沉淀进 skill |
