# 测试简报：检验“风格一致，形式不同”

用途：每次修改风格四章后，让 AI 用本 skill 对下面的虚构品牌跑第 1–3 阶段（简报 → 概念配速写 → 推荐概念的原型），检查：
1. **气质是否到位**：通过 `style-dna.md` 的整体试金石与 `philosophy.md` 的自检。
2. **形式是否不同**：三个品牌取的元素、组合方式、字形性格彼此不同，也与 `cases/` 不同。

跑测试的 AI 不要读 `evals/records.md`，以免被以前的结果影响。

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E1 | 衡隙精工 Gapwright | 为汽车与医疗设备做精密轴承与微型齿轮的制造商，客户是工程采购；想显得精确、可靠、国际化 |
| E2 | 小行星科学馆 Asterhouse | 城市里的儿童科学馆，6–12 岁孩子和家长；想要好奇、聪明，但不要卡通 |
| E3 | 齐发薪 Pulsepay | 给中小企业发工资、算个税的 SaaS；客户是老板和财务；想要可信、准时、轻松 |

第二组（同一组连跑两三轮后换用）：

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E4 | 复跑运动康复 Rerun Clinic | 跑者与运动员的康复诊所；想要专业、积极，不要医院感 |
| E5 | 双岸渡轮 Twin Quay Ferries | 连接两座海港城市的渡轮公司；乘客与货运；想要稳、准点、开阔 |
| E6 | 回响唱片 Afterring Records | 独立音乐厂牌，做电子与实验音乐；想要先锋、克制，不要夜店霓虹 |

## 判定

| 检查 | 通过标准 |
|---|---|
| 母题来源 | 每个概念都写明来自名字或业务的哪里 |
| 不同 | 15 个概念（3 个品牌 × 5）中，以案例造型语言为主的不超过 2 个 |
| 跨品牌不撞形 | 三个品牌的推荐原型放在一起，一眼能分开 |
| 旋钮 | 每个品牌至少两个旋钮与案例不同 |
| 结构先行 | 第 3 阶段原型先以黑白成立；带色版本另附 |
| 流程 | 每阶段结束都等用户确认，并写入 decisions.md |
| 速写 | 第 2 阶段每个概念都有黑白速写（字标关键字母 + 符号），并写了字形图形化自查 |
| 字形图形化（本风格） | 推荐字标读不懂也像一个被设计的形；符号能独立成物；说得出符号取自字标哪几处 |
| 组合不同（本风格） | 三个品牌的符号用的不是同一种组合方式；都不是“首字母放进方块” |
| 修正几何（本风格） | 曲线与转角出自同一个方度；字形由构造而来，不是现成字体 |
